# ESO.WareGuild

Item management add-on for Elder Scrolls Online guild banks.

Configure a guild in WareGuild's settings before adding rules. With [LibCustomMenu](https://www.esoui.com/downloads/info1146-LibCustomMenu.htm) installed, right-click an item in the keyboard interface and select **WareGuild**, then **Withdraw** or **Deposit**. Enter a target quantity (1–200), or choose **All stacks** if the item is stackable. A non-stackable item uses a quantity of 1. Select one or more configured guilds and save. This adds rules without transferring items immediately. Numeric rules use the existing target totals: the backpack for Withdraw and the guild bank for Deposit.

Use the **Withdraw Items for Daily Writs** rule to retrieve matching finished items and the remaining materials in a single bank run, subject to stock, permissions and available backpack space. See [CHANGES.md](CHANGES.md) for release details.
